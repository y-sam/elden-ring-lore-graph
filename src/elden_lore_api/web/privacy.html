Privacy notice

What the archive processes

The archive requires no account and sets no advertising or analytics cookies.

Questions and technical logs

Requests are processed to retrieve graph evidence and assemble an answer. Technical logs may contain timestamps, endpoint paths, errors, an answer identifier and a transient network address used for abuse prevention. Question text is not written to application logs unless the operator explicitly enables diagnostic logging.

Generative answers

When the interface identifies an answer as generated, the question and a bounded set of project-authored claims and evidence summaries are sent to the configured model provider. Unsupported questions are not sent. Deterministic and fallback answers make no model-provider call.

Feedback

If you submit feedback, the rating, optional reason, optional comment, question, answer identifier and referenced claim identifiers are stored for moderation. Do not include names, email addresses or other personal information. Feedback never changes canon automatically.

Retention and control

Operational logs and pending feedback should be retained only as long as needed for reliability, abuse prevention and editorial review. Requests concerning stored feedback can be opened through the project owner's public GitHub profile.
